- 旧集合逻辑只要求靠近第一个 Spawn 的四格范围；已在范围内的队员没有移动意图，附近经济通道被持续占用。其他成员仍在 boost 时，整个编队直接跳过移动。BetterMove 的 `dontPullMe` 锁还会禁止友军推让这些待命队员。
