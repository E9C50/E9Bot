# shard1 断产复发与完整身体接续

2026-10-10 官服 shard1/E39N5 在 tick 74243126 的现场：RCL6，出生池 300/2200，Spawn 空闲，Storage 和两个矿区 Container 均空，两个 Source 均满。仅存一只 24 部件、600 容量的矿区 Filler，没有矿工；Terminal 仍有 8509 能量。CPU 约 1，当前阻塞为经济链路而非 CPU 超时。

## 可复现的问题与修复

- 原矿区 Filler 只收集指定矿区输出，完全断产后无法调用 Terminal 库存。现在临时使用现有搬运工，按第一个完整矿工的实际缺额借能量；普通路径仍保留 Terminal 50000。借款记录恢复前余额与保留线的较小值，恢复后优先还款，再由原 Manager 补足正常储备。
- 第一个完整矿工出生后，临时搬运继续收集已生产矿区的能量直接补出生池，直到专用 Storage 配送工可用。专用配送仍在出生时不会提前移交；有货在途先交付，永久矿区绑定和原加载状态保持。临时供能标记只认可当前或上一 tick，避免矿工同时离矿自运。
- 专用配送的优先级判断不再把矿区 Filler 当作完整的出生物流；出生池、库存和在途资源共同决定完整出生资金。关键矿工和明确的寿命接续排在 Manager 前，健康扩产仍使用原优先级。
- 替补提前量使用下一只完整身体的出生时长、单 Spawn 顺序出生、路程、当前占用及实际到货收入对应的筹资时间。没有到货收入时不虚构 1 能量/tick；资金不足且当前矿能不足时才加实际再生等待。矿工、矿运和专用配送均提供重叠接续，健康前驱自然工作至死亡。
- 发育房消费预算先扣完整经济单位的维持费，再分配维修、建造、升级；重叠的前驱和后继不重复计费。没有工作经费时不新增普通消费单位，控制器紧急降级与基础设施启动保留例外。
- 发育修墙工现在执行发布的 WORK 预算，完整身体不再每 tick 耗用全部 WORK。受攻击或战争状态即时维修。旧升级单位继续工作，其实际消费先从新单位预算扣除。
- 常态 Filler 取 Terminal 时限定保留线以上的量，并共享同 tick 提款承诺，防止多个搬运工同时越过保留线。生产识别在每 tick/shard 仅遍历一次全局单位，正常生产路径不预览恢复目录。
- Terminal 发送、市场成交及手续费、Manager/Processer 提款共用同一能量承诺，避免原生 Store 尚未结算时多用同一余额；普通 Filler 无需为此扫描全房资源。
- Manager 补终端时，Storage 先保留一只完整单位的出生容量资金；中央 Link 在 Storage 不足时先入库。目的标记跨 tick 保持这批 Link 货回 Storage，防止下一 tick 又被自动转入 Terminal。

本轮净预算覆盖本地常驻经济人口。自动外矿的额外补员成本尚未纳入；当前 E39N5 没有自动外矿队伍。
